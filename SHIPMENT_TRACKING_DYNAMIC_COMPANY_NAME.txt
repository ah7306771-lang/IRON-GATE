Iron Gate – Dynamic Customer Company Name

What changed:
1) customer-tracking.html no longer hardcodes IRON GATE.
2) shipment-track Edge Function returns only tracking.companyName.
3) The name is read from the main app Settings → Appearance → “اسم الشركة الظاهر”
   (settings.data.branding.companyName) for the link's company_id.
4) If that field is empty/unavailable, it falls back to companies.name for the same company code.
5) No full settings data, customer data, balances, or sales-order payload is exposed.

Deploy:
A. GitHub: replace customer-tracking.html in the IRON-GATE repository root.
   Keep developer-logo.webp in the same folder next to customer-tracking.html.
B. Supabase: Edge Functions → shipment-track → Code, replace the whole source with
   shipment-track-index.ts, then Deploy updates.
C. Keep Verify JWT with legacy secret OFF as previously selected; the endpoint expects
   public GET and validates JWT itself for authenticated POST create/revoke.
D. After deployment, create a NEW tracking link (or use an active valid link) and test.

Important:
- The customer name will update from the configured display name in the main app.
- If settings.data.company_id is not accessible/schema differs, the safe fallback is
  companies.name. No fixed IRON GATE text is left in the customer header.
- No runtime/database deployment has been performed by preparing these files.
